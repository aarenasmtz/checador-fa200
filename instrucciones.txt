4. ABSTRACCIÓN BIOMÉTRICA
============================================================

ESTA PARTE ES CRÍTICA.

El sistema NO debe depender directamente de FA200.

Crear una abstracción:

IBiometricProvider

Por ejemplo:

public interface IBiometricProvider
{
    Task<bool> TestConnectionAsync(
        BiometricDevice device,
        CancellationToken cancellationToken);

    Task<IEnumerable<BiometricEvent>> GetEventsAsync(
        BiometricDevice device,
        DateTime? from,
        CancellationToken cancellationToken);

    Task SyncEmployeeAsync(
        BiometricDevice device,
        Employee employee,
        CancellationToken cancellationToken);

    Task DeleteEmployeeAsync(
        BiometricDevice device,
        string employeeCode,
        CancellationToken cancellationToken);
}

Implementar inicialmente:

MockBiometricProvider

Posteriormente:

Fa200BiometricProvider

La aplicación nunca debe saber directamente cómo se comunica FA200.

Debe consumir IBiometricProvider.

Esto permitirá agregar en el futuro:

ZKTecoProvider
HikvisionProvider
OtroProvider

sin modificar la lógica de asistencia.
